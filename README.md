# Guitar Theory Lab

Interactive web application for exploring guitar theory:

- Full interactive fretboard visualizer with scales, modes, and chords
- All major scale modes + pentatonics, blues, harmonic/melodic minor, etc.
- Chord positions via CAGED system (major/minor shapes)
- Interval labels for every note
- Circle of Fifths with related progressions
- Common chord progressions in any key
- Tablature generation for scale positions

## Usage

Open `index.html` in a modern browser (or host on GitHub Pages).

Standard tuning: EADGBE.

## Features

- Dark, clean interface inspired by modern editorial design
- Prefer flats/sharps toggle
- Generate ASCII tablature for multiple positions
- Clickable circle of fifths

Built as a self-contained static site for easy deployment.
